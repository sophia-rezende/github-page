# github-page

Portfólio acadêmico desenvolvido utilizando GitHub Pages.

## Objetivo

Este projeto tem como objetivo apresentar:
- estruturação de repositórios;
- versionamento;
- organização de projetos acadêmicos;
- publicação de página web com GitHub Pages.


## Projetos

### Acadêmicos
- Banco de Dados
- Lógica de Programação

### Pessoais
- Projetos independentes e estudos
